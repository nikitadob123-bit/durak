# Дурак онлайн — постоянная ссылка

Это только страница-переадресация: https://nikitadob123-bit.github.io/durak/

Она читает `url.json` (текущий адрес игрового сервера, обновляется автоматически) и перенаправляет туда,
сохраняя параметры — например, ссылка-приглашение `…/durak/?room=ABCD` ведёт сразу в комнату ABCD.
