# 🃏 Дурак онлайн

**Играть:** https://nikitadob123-bit.github.io/durak/

Карточная игра «Дурак» (подкидной и переводной) для компании друзей — прямо в браузере, без установки и без регистрации. Удобно с телефона, работает и на компьютере.

## Как играть

1. Откройте ссылку, введите имя и нажмите **«Создать комнату»**.
2. Отправьте друзьям ссылку-приглашение (кнопка «Копировать ссылку» / «Поделиться») или 4-значный код комнаты.
3. Друзья открывают ссылку, вводят имя и жмут **«Войти»**. В комнате от 2 до 6 игроков; пустые места можно занять ботами («Добавить бота»).
4. Хозяин комнаты выбирает режим (подкидной / переводной), колоду (24 / 36 / 52) и правило подкидывания, затем — **«Начать игру»**.
5. Ход: нажмите карту (она приподнимется), нажмите ещё раз — карта уйдёт на стол. Отбиться — выберите карту и нажмите карту на столе. Кнопки «Беру», «Бито», «Пас», «Перевести» появляются, когда они доступны.

## Как это устроено

* Это статический сайт на GitHub Pages — своего сервера нет.
* Связь между игроками — через Supabase Realtime (бесплатный тариф): у каждой комнаты свой канал `durak:КОД`.
* «Сервером» служит браузер хозяина комнаты: он раздаёт карты, проверяет каждый ход и рассылает каждому игроку только его собственную руку (личные данные шифруются ключом игрока: ECDH P-256 + AES-GCM).
* **Надёжность:**
  * короткие обрывы связи переживаются незаметно: клиент сам переподключается, ход повторяется до подтверждения, состояние досинхронизируется;
  * перезагрузка страницы возвращает на своё место (токен в `localStorage`);
  * хозяин хранит всю партию у себя — после перезагрузки игра продолжается с того же места;
  * если хозяин пропал, игра ставится на паузу «Ждём хозяина…», а через ~45 секунд комнату подхватывает следующий игрок (у него есть свежая зашифрованная копия партии) — и игра идёт дальше; за пропавшего игрока через минуту начинает ходить бот;
  * при сворачивании вкладки на телефоне и возвращении — мгновенная ресинхронизация.
* Лёгкий запрос к базе при каждом открытии страницы и ежедневный GitHub Actions не дают бесплатному проекту Supabase «уснуть» (пауза после 7 дней без активности). Файл действия лежит в `tools/keepalive.yml`: чтобы включить, переместите его в `.github/workflows/keepalive.yml` (через веб-интерфейс GitHub или с токеном со scope `workflow`).

Это собранная версия; исходники и правила (`config/rules.json`) — в приватном репозитории `durak-online`.
